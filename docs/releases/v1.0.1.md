# 知守 Memo / AssetAgent v1.0.1

v1.0.0 的修复版本，保持本机单用户、单进程运行方式。提供源码归档，不包含预构建镜像或桌面安装包。

## 修复

- 问答历史按当前安全策略重新脱敏，避免旧历史绕过新增规则。
- 已删除的保险柜条目会重新保存，后续提交复用新条目。
- 重复提交相同文字仍创建独立报告和维护任务，同时复用已有来源与凭证。
- 同一文件在不同附件组合或顺序中保持稳定来源和私密引用。
- 旧问答响应不再清空新会话或随后编辑的草稿。
- 快速切换 Wiki 页面时，过期响应不再覆盖当前正文、加载状态或错误。

## 验证与限制

后端 488 项、前端 92 项测试通过；类型检查、ESLint、前端构建与依赖锁检查通过。Linux ARM64 Docker 镜像构建及隔离环境浏览器回归通过；模型和保险柜使用测试替身。本轮未验证真实外部模型兼容性、真实 Vaultwarden 故障恢复或旧开发数据无损迁移。

详细证据见[修复验收](../verification/review-fixes-2026-09-24.md)。沿用 [v1.0.0 的功能范围与已知限制](v1.0.0.md)。

## 安装与升级

新安装见 [README](../../README.md#快速开始)。已有环境先停止维护写入，一致性备份数据库、Wiki/Raw/Private Raw、密钥、证书和 Vaultwarden，再切换 `v1.0.1` 并执行 `docker compose up -d --build`。本次不引入数据库结构迁移。

切换代码不能撤销已经发生的数据更新；回退需使用相互匹配的代码和数据备份。
