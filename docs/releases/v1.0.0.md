# 知守 Memo / AssetAgent v1.0.0

首个源码发布版本，面向本机单用户的个人 Wiki 维护与问答。使用 Docker Compose 从源码构建，不包含预构建镜像或桌面安装包。

## 主要功能

- 固定问答/维护会话：问答只读，维护才修改知识库；删除会话不删除知识。
- 文本和多文件导入：Markdown、TXT、CSV、Excel、Word、纯文本 PDF；先校验，再进入统一安全处理流程。
- 双栏资料审查：对照本机原文与发送内容，保护或取消保护，修改引用名称与备注。Excel 保留工作表和单元格位置。
- 单次确认后后台维护：立即创建任务，后台生成计划、编写页面、保存资料和更新 Wiki；任务展示阶段、结果、待核对事项及失败原因。
- LLM Wiki：知识模型按目录读页面或调用本地 BM25 文本搜索；无须配置向量、Embedding 或重排模型。
- 程序安全检测与可选本地模型增强；敏感信息可写入 Vaultwarden，Wiki 只保留可读私密引用。
- 原件按字节归档至 Private Raw；每个附件保留独立来源，整批共用一份报告、一个任务。
- 失败补偿覆盖保险柜、Raw、Private Raw、Wiki、派生索引和来源记录；持久化日志支持重启恢复，不删除复用的历史数据。
- 简化设置：模型配置、安全策略、安全事件、通用；安全模型只有一个管理入口。

## 安装

按 [README](../../README.md#快速开始) 初始化密钥、证书和 Vaultwarden 账号，配置知识模型后使用。Release 自动附带 GitHub 源码归档；不包含任何用户资料、账号或密钥。

## 已知限制

- 跨系统采用补偿事务，不是分布式数据库事务。保险柜离线或磁盘故障可能暂时阻止清理；日志保留到补偿成功，期间暂停后续维护。
- 每批最多 20 个附件，总大小默认 10 MB。Private Raw 采用逻辑隔离，不是操作系统权限沙箱；应用无原件读取接口。

- **不支持 OCR**：图片、扫描 PDF、复杂 Office 文档需先整理成支持的格式；具体校验范围见 README。
- **检测不是零遗漏保证**：启用确认模式可以人工核对；使用云端知识模型时，处理后的内容仍会发送至配置的服务。
- 安全模型当前主要补充敏感识别；报告名称、动作与保存结构主要由程序生成并允许确认时修改，不承诺自动理解任意业务描述。
- 旧检索依赖和部分兼容 API 仍存在，设置入口已经移除；源码安装与镜像体积仍有优化空间。
- 没有任务取消/删除/重试入口。失败后需重新发起维护，不承诺旧开发版本的数据无损迁移。

## 验证范围

详细用例见 [发布验收](v1.0.0-acceptance.md)。

- 发布准备阶段本地后端测试 482 项、前端测试 85 项通过；类型检查与前端构建通过。
- ESLint 0 错误、5 条已有警告；前端测试仍有 sidebar 嵌套 `li` 的既有警告。
- 临时目录的真实 API/Worker 测试覆盖混合格式批次、原件字节一致性、单任务、取消、手动保护、保存失败回滚与重启恢复；模型与保险柜使用测试替身。
- Bitwarden 适配器经测试 CLI 验证响应丢失后的补偿；未在用户的真实保险柜上注入破坏性故障。
- 浏览器验收使用临时工作区和合成资料，不等于所有用户文档和所有模型均兼容。

## 升级与回退

这是首个正式源码版本。旧开发环境升级前，先备份 Wiki/Raw、运行数据库、密钥、证书和 Vaultwarden；保持服务停止写入时进行一致性备份。不要在真实数据上运行演示数据清理脚本，不要删除数据库冒充升级。

切换代码版本不能撤销已经发生的数据更新；需要回退时，代码、数据库和保险柜应使用相互匹配的备份。
