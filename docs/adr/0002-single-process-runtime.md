# 单进程运行：禁止多 worker / 多副本

"查重 → 凭证写入 → 落盘"的互斥窗口由进程内 asyncio 锁保证（app/ingest/finalize.py），Vaultwarden 与 bw CLI 没有分布式锁，登录会话态也只存在于单个适配器实例。多进程会使锁失效，并发确认可能把同一秘密重复写入凭证库；而单用户场景的性能瓶颈是 LLM 调用，多进程没有任何收益。

**后果**：uvicorn 不加 --workers、不扩容副本（docker-compose 已注释警示）；后台队列（待处理凭证、编译任务）解决的是容错与重试，不是并发。若未来确需多进程，必须先引入跨进程互斥（文件锁/单一写入者）并取代本 ADR。
