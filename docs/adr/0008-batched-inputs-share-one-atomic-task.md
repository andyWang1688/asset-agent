# 一轮维护允许多个 Source，共用一个原子任务

手动文字与文件上传在解析后进入同一套安全和 Wiki 流程；一次维护可以上传多个文件，每个文件保留为独立 Source，但共用一份报告和一个维护任务。任一文件解析、安全处理、保险柜保存或 Wiki 编译失败，整批停止并清理本轮临时副本，不留下半成品；任务按业务事务处理，已产生的结果使用补偿清理。附件存在时输入文字是本轮整理要求而不是文件 Raw，没有附件时输入文字本身就是 Source；问答 Session 不提供附件入口。

## 1.0 实现边界

保险柜与本地文件不共享数据库事务，因此采用持久化补偿日志，而非宣称跨系统瞬时原子提交。失败时仅删除本轮新建条目，恢复既有 Wiki 与来源；复用的历史原件和凭证不删除。保险柜响应丢失通过本轮事务标记识别已创建条目，禁止盲重试创建。补偿故障时暂停后续维护，重启先清理遗留事务；这不是重新执行失败任务。
