# 安全模型是可选增强，不是基础依赖

AssetAgent 的基础安全闭环必须在没有安全模型时完整可用：程序使用正则和熵值识别敏感内容，生成固定格式报告，确定脱敏动作、私密引用和 Vaultwarden 条目结构。启用本地安全模型后，它只承担两项锦上添花的工作：补充识别程序可能遗漏的敏感内容，以及补充报告中的敏感类型、可读名称、说明和字段信息；模型不能取消程序发现、绕过脱敏或直接写入 Vaultwarden/Wiki。

Vaultwarden 只接收经过程序校验后的结构化报告，模型输出不直接作为执行指令。安全模型不可用、输出非法或超时时，系统回退到程序生成的 Finding 和报告，不能因此阻断基础维护流程；安全模型只允许使用本地端点，禁止把原文发送到公网。
