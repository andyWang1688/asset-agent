# 资料审查交付验收

## 已接入的正式路径

维护对话提交文字或文件 → 格式校验 → 安全检测 → 确认模式下居中双栏审查 → 用户确认内容后生成维护计划 → 确认执行 → 保险柜/Raw/任务 → Wiki。
自动模式仍沿用原流程，不弹审查页。

- Excel / CSV 按真实工作表、行列坐标显示；手动文字、Word、文本 PDF 按提取文本显示，不伪装成原文件排版。
- 左右联动选择、同步滚动；支持整列、Shift 多选、人工补标、取消保护、撤销、名称和可选备注。
- 未选择时不显示编辑区；选中项的名称、备注、保护操作在同一区域。不要求用户配置保险柜技术字段。
- 人工补标只上传原文坐标，由后端从加密暂存中提取原值。名称默认生成，改名后引用名与保险柜名一致。
- 审查接口不读 Private Raw、不调用模型；成功响应禁止缓存。报告未确认时不创建维护任务。
- 打开审查页不自动生成计划；用户确认内容后才让知识模型生成计划。再次编辑使旧计划失效；生成计划/提交期间锁定修改。
- 审查失败、无有效预览或名称为空时禁止继续；关闭页面销毁前端原文状态，忽略迟到响应。

## 边界

- 不是原生 Word/PDF 高保真渲染；不含 OCR。复杂文件按格式门槛拒绝，不宣称所有文件都能无损提取。
- 人工新增保护单位为单元格或文本行；已有检测片段可分别取消/改名。暂不支持任意字符范围框选。
- 草稿只在当前审查窗口内存中保留；返回对话后再次打开会重载系统检测结果，不持久化人工修改。
- 大文件最高限制沿用现有提取上限；未进行 20 万单元格级浏览器性能验收。
- 已完成真实已配置知识模型 + 真实 Vaultwarden + 真实 Worker 联调，并部署正式 Docker；未提交 Git。
- 现有 sidebar 测试仍打印嵌套 li 警告；现有 UI 组件与 Demo 有 Fast Refresh lint 警告，此次不修改无关路径。
