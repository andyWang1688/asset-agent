# 安全策略终版设计（取代 2026-08-27 polish 稿的相应部分）

2026-08-28 定稿。多轮 grill 后的最终形态：用户视角、两档旋钮、配置细则 tabs。

## 导航与布局

1. 一级侧边栏设置区四个入口：模型配置 / 检索配置 / 安全策略 / 安全事件；
   无状态点、无设置页内二级导航。
2. 内容区自适应：流式宽度、左对齐、最大约 1200px，任何屏幕无死白。

## 安全策略页结构

顶部常驻「处理方式」：
- 默认模式（默认）：扫完按既定规则自动处理，无人工步骤；
- 确认模式：每份资料入库前过确认页（无命中也过一眼）；
- 永远生效行（不随档变）：秘密原文永不发给模型；对话发凭证一律拦截；回答永远复扫。

「配置细则」四个 tabs（深链 /settings/security#regex 等，刷新不丢）：
- 正则：统一规则清单（内置/已覆盖/自定义），开关/覆盖编辑/恢复默认/新增自定义；
  搜索框 + 每页 20 分页；不限条数；规则数 >50 显示非阻断提示
  「规则较多可能影响扫描性能，建议定期清理不再使用的规则」。
- 关键词：开关 + 标签加删（关键词联想层）。
- 熵值判定：开关 + 灵敏度三档（保守/平衡/敏感，各带一句后果说明）。
- 安全增强模型：模型卡（端点/Key/测试）从模型配置页挪来；
  人话说明：可选的本地 AI 辅检，只加严不放松、仅本机/内网端点。

确认页三动作：同意（按建议一键处理）/ 拒绝（整份丢弃）/ 按我说的做
（展开逐项裁决 + 脱敏预览编辑）。

## 部署级配置（不进 UI，进部署文档）

默认处置（actions.defaults）、自定义规则护栏（超时/长度上限）、
关联窗口/命中加成、熵单份上报上限。YAML 编辑器整体退出 UI。

## 术语（已进 CONTEXT.md）

默认模式/确认模式；模式匹配/关键词联想/乱串检测；确认页三动作。
技术名（正则/上下文/熵、gate、shannon）只出现在部署文档与高级语境。

## 拍板决策（执行者不得更改）

1. 两档旋钮是预设，不暴露灵敏度独立旋钮；熵三档映射阈值预设。
2. 规则无条数上限；>50 只提示不阻断。
3. 确认模式下无命中资料也过确认页。
4. 永远生效行不可配置、不可隐藏。
5. 模型配置页只管知识库模型，文案同步修改。
6. 边界：前端设置页 + 策略结构化 API；扫描管线、编译、凭证零改动。

## 怎么算完成

- 四入口一级导航、自适应布局、无状态点；
- 安全策略页 = 处理方式常驻 + 四 tabs，深链有效；
- 规则搜索/分页/不限数/>50 提示/覆盖/恢复全可用；
- 确认页三动作全流程可用；YAML 编辑器在 UI 中消失；
- 部署级配置有部署文档承接；
- 前后端测试全绿，typecheck/lint 通过。

## 不做什么

- 不做规则条数硬上限；不做灵敏度独立旋钮；
- 不做 YAML 编辑 UI；不做状态点；
- 不动对话沉淀知识/滑动窗口提示/Excel（另行立项）。
