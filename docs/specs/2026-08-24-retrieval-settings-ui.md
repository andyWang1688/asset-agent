# 这次要做什么：检索配置搬上设置页（模型可选、可下载、有兜底）

2026-08-24 定稿。背景：问答引擎换成 LlamaIndex 后，embedding/重排模型目前只能用环境变量配，
普通用户够不着；模型权重缺失时问答直接报错，没有兜底。本次把检索配置做成页面能力。

## 要做成什么样

1. **设置页新增"检索配置"区**：后端路线（本地 sentence-transformers / 本地 Ollama / 云端）、
   模型、重排器开关与模型，都能在页面上配。
2. **推荐列表 + 一键下载**：中文场景推荐 BGE 系（embedding 与重排各给入门款），
   点下载由后端拉到本地持久卷，进度可见；网络失败时给出明确错误和 Ollama 替代路线指引。
3. **自定义模型**：推荐列表之外的模型可手填（本地填 HF 模型 ID、Ollama 填模型名、云端填任意兼容模型名）；
   自定义模型同样走下载按钮；保存前有"测试"按钮验证模型可用（嵌一段文本、返回维度）。
4. **没配好不装死**：embedding 不可用时问答**降级为纯关键词召回并明示**（UI 提示"语义召回未启用"），
   不拒绝提问。
5. **换模型自动重建索引**：保存导致向量不兼容的配置变更时自动触发索引重建，页面显示进度；
   用户不需要理解"向量不兼容"。
6. **云端显式警告**：选择云端端点时强制展示"知识库内容将发送到该端点"警告并要求勾选确认。

## 已经拍板的决策（执行者不得更改）

1. 降级 + 提示，不是拒绝提问（与知识库模型未配置的拒绝行为不同，不要混淆）。
2. 配置变更自动重建索引，不做手动选项。
3. 云端选项必须带显式警告 + 确认勾选。
4. 配置持久化复用现有加密存储模式（API Key 走既有加密），不新增明文存储。
5. 模型权重存数据目录持久卷；容器重建不丢模型。
6. 边界：只动问答子系统配置与前端设置页；安全管线、编译管道、凭证隔离零改动。
7. 环境变量配置继续有效（页面与环境变量同语义，页面写入优先），不破坏现有部署。

## 怎么算完成

- 页面完成"选推荐模型 → 下载 → 测试 → 保存 → 自动重建"全程，不碰命令行；
- 删除模型文件后提问：得到关键词召回结果 + "语义召回未启用"提示，不报错；
- 自定义模型填写、下载、测试路径与推荐模型一致；
- 云端警告不勾选则无法保存；
- 现有测试全绿，安全回归不放松。

## 不做什么

- 不做模型量化/微调等高级选项。
- 不做多套检索配置档案（单实例单配置）。
- 不改知识库/安全两个 LLM 角色的现有设置页区域。
