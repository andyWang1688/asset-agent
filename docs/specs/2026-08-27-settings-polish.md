# 这次要做什么：设置中心打磨（布局/文案/去重/事件表）

2026-08-27 定稿。背景：设置中心上线后实测反馈——宽屏比例失调、徽标过小、
自定义规则 20 条上限武断、安全策略 YAML 与检测规则模块功能重复、安全事件列表难用。

## 要做成什么样

1. **真两栏布局**：导航左固定约 220px，内容区左对齐吃满剩余宽度（上限约 1100px），
   删除居中窄容器；状态点语义不变（绿正常/灰无记录/黄降级/红需注意）。
2. **徽标可读性**：必配/可选/已覆盖等徽标字号与内边距加大到可读水平。
3. **自定义规则上限 20 → 100**；单条正则的超时/长度护栏不变。
4. **YAML 编辑器去重**：只保留友好 UI 未覆盖的配置（闸门模式、熵参数、上下文关键词等）；
   规则部分不再可编辑，展示只读说明 + "去检测规则管理"跳转。
5. **安全事件表格化**：表头（时间/类型/详情）、分页（每页 20 条+翻页）、
   RefreshCw 风格刷新按钮、每 5 秒自动轮询；手动刷新保留。

## 已经拍板的决策（执行者不得更改）

1. 布局改两栏，不做居中窄容器。
2. 规则上限 100，护栏（长度/超时/白名单）不放松。
3. YAML 编辑器的规则键只读化，数据仍存同一策略文件，规则模块是唯一编辑入口。
4. 自动轮询 5 秒；页面离开时停止轮询，不泄漏定时器。
5. 边界：前端设置页 + 策略常量；扫描管线、编译、凭证零改动。

## 怎么算完成

- 宽屏（≥1440px）下两栏布局无明显死白；导航与内容对齐协调；
- 徽标肉眼可读；自定义规则可加到 100 条且第 101 条被友好拒绝；
- YAML 编辑器改规则键不生效（或不可改），跳转链接可用；
- 安全事件有表头、可翻页、5 秒自动刷新可见（网络请求可观察）、离开页面轮询停止；
- 前端 typecheck/lint/测试通过，后端测试全绿。

## 不做什么

- 不做事件全文搜索/导出。
- 不做设置项全局搜索。
