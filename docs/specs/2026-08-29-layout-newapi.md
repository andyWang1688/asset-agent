# 布局改版：照抄 New API 壳子 + 安全页细节收尾

2026-08-29 定稿。根因：对话页居中、设置页左对齐、窄容器三种版心混用导致不协调。
参照 New API（QuantumNous/new-api）的 PageLayout：固定侧栏+面包屑+内容区吃满宽度区内滚动。

## 壳子

- 侧栏固定宽、独立滚动（现状保留）；
- 面包屑条之下为内容区：吃满剩余宽度、高度=视口-顶栏、区内纵向滚动（窗口不滚）；
- 页面内容=全宽卡片（内边距统一 p-6 级），删除一切居中窄容器与左对齐 max-width；
- 表格超宽时卡内横向滚动；
- 对话页例外：会话列在内容区内居中（聊天产品通例）。

## 安全页细节（随本轮收尾）

1. 删除「永远生效」展示行（不变量代码与 README 保留，UI 不贴）；
2. 正则 tab 补一句说明："匹配上以下任一规则的内容即视为敏感信息；可新增自定义规则，或覆盖/停用内置规则。"
3. 规则清单改 New API 式表格：
   顶栏=搜索+类型筛选+右上"新增规则"；
   列=名称/类型/来源/说明(含示例命中)/状态(开关)/操作(覆盖编辑、恢复默认、展开正则，图标+⋯菜单)；
   底栏=总计+每页 20+页码；>50 非阻断提示保留，置于表格上方。

## 拍板决策

1. 全站统一这一套版心，不允许页面自创容器；
2. 对话页会话列居中是唯一例外；
3. 功能行为零回退，纯视觉与结构改版。
