# 这次要做什么：设置中心改版（导航分层 + 规则统一 + 内置规则可改）

2026-08-25 定稿。背景：设置页是单页长滚动，五个模块样式同质、层级不醒目；
检测规则按"内置/自定义"两块实现视角摆放，内置规则看不到匹配内容、不能修改。

## 要做成什么样

1. **设置中心布局**：左侧模块导航（模型配置 / 检索配置 / 检测规则 / 安全策略 / 安全事件），
   每项带图标与状态点（红=需要注意，黄=降级，绿=正常）；右侧一次只显示一个模块，
   模块标题区做重（图标+标题+说明+状态徽标），模块内条目做轻。
2. **规则统一成一个列表**：不再分内置/自定义两块。每条规则展示：名称、类别、
   来源标签（内置/自定义）、"它匹配什么"（描述+示例命中，正则折叠在高级展开里）、启停开关。
3. **内置规则可改**：支持覆盖修改（改正则模式或类别），底层实现为停用原规则+生成覆盖层，
   被覆盖的规则带"恢复默认"；自定义规则的表单新增保留。

## 已经拍板的决策（执行者不得更改）

1. 布局采用左侧导航设置中心，不是单页锚点。
2. 内置规则的修改走覆盖层（策略文件新增覆盖配置），不改代码内置规则表；恢复默认=删覆盖+恢复启用。
3. 规则内容默认展示"描述+示例命中"，正则只对高级展开展示。
4. 内置规则需要补齐中文描述与示例元数据（随规则表维护）。
5. 策略校验护栏不放松：覆盖的正则同样受长度/超时/校验函数白名单约束；策略与审计不含秘密。
6. 状态点语义：模型未配置=红；检索降级/规则全停用等异常=黄；正常=绿。不允许为了好看谎报状态。
7. 边界：前端设置页 + 策略层 + 规则元数据；安全扫描管线、编译管道、凭证隔离零改动。

## 怎么算完成

- 五个模块经左侧导航切换，各自独立渲染，状态点与实际状态一致（用未配置/降级场景验证）；
- 规则列表单块呈现，内置规则可见描述与示例、可覆盖修改、可恢复默认，覆盖后检测行为即时生效（测试验证）；
- 自定义规则新增/启停行为不回退；非法覆盖被校验拦截且错误友好；
- 前端 typecheck/lint/测试通过，后端测试全绿。

## 不做什么

- 不做设置项搜索。
- 不做多用户/权限相关的设置隔离。
- 不动模型配置区内部的卡片交互（只搬进新布局）。
