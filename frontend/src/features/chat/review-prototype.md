# 资料审查原型

唯一布局：左侧本机原文、右侧发送内容，同步滚动；底部只编辑名称和可选备注；名称统一用于引用展示与保险柜保存。技术性类型和字段由系统处理，不要求用户填写。
启动：在 frontend 运行 `pnpm dev --port 5178 --strictPort`。
地址：http://127.0.0.1:5178/review-prototype.html

已删除 A/C 方案、布局参数、切换器、单栏模式和侧栏适配。
支持单项/整列/Shift 多选、保护所选、取消保护、撤销、名称必填校验。已移除“保护所有相同内容”；取消保护使用红色描边按钮。Excel 页签明确标注为工作表。
顶部保留一个原型标识；数据和保存均为内存模拟，不调用真实 API。
Word/PDF 是样例排版，不是实际文件渲染器，不支持任意文字范围选择。

未选择时隐藏编辑区；选中后名称、备注与保护操作同行显示，多选时提供批量操作。撤销放在底部，清除选择后仍可使用。
